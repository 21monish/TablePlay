# TablePlay Customer

Flutter Android client for paired restaurant tablets. It provides the menu, cart, ordering, live order status, table service requests, server-controlled game access, responsive drawer/sidebar navigation, and local application updates.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

Android release builds require the protected signing setup described in `../docs/LOCAL_APP_UPDATES.md`. Do not distribute or publish debug-signed APKs.
